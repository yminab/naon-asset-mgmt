# 나온웍스 자산 관리 시스템 v3

신규 설치: `sudo ./install.sh`

추가 기능: 3자리 자산번호, 일반/시료 구분, 시료 사양, 시료 신청/승인/불출/반납, Excel Import/Export, 자산 복합필터, 권한 한글 표시.

## v4
- 입출 현황 MariaDB 호환 쿼리 수정. 상관 서브쿼리 JOIN 대신 최신 활성 신청을 집계 테이블로 조인.

## v5
- 입출현황 시료서버 조회를 단순 자산 조회 + 자산별 최신 활성 신청 조회로 분리하여 MariaDB 쿼리 호환성 문제 제거.

## v6
- MariaDB 예약어 current_user SQL alias 제거.
- Python io 모듈과 io() Flask endpoint 이름 충돌 제거. Excel Export BytesIO 오류 수정.

## v12
- 누적 요구사항 통합 신규 설치본: 라이선스 신청/승인/선택지급/회수, 시료 불출 레이아웃 제거, 상태 삭제, 장소/평가/레이아웃 설정, 월점검 상세.

### v15
